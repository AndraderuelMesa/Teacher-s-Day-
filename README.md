💙 Happy Teacher's Day | Sir Randy Bello

A simple and interactive **Teacher's Day appreciation website** created for **Sir Randy Bello**, a Web Development instructor.

This project uses **HTML, CSS, and JavaScript in a single HTML file**. It includes animations, dark/light mode, a teacher photo, and an interactive Teacher's Day letter.

🎓 Project Overview

This project is a digital Teacher's Day card created to show appreciation and gratitude to a teacher.

The website features a modern **blue and black theme**, animated background effects, and an interactive letter.

## ✨ Features

* 💙 Teacher's Day greeting
* 👨‍🏫 Teacher profile section
* 🖼️ Teacher photo
* 🌙 Dark mode
* ☀️ Light mode
* ✨ Animated background particles
* 🔵 Glowing visual effects

🛠️ Technologies Used

HTML: Used to create the structure and content of the Teacher's Day card.
CSS: Used for the layout, colors, animations, responsive design, dark/light mode, glowing effects, and letter popup.
JavaScript: Used for the dark/light mode switch, letter popup, closing functions, ESC key function, and animated background particles.

📁 Project Structure

The project contains the following files:
  index.html** – Main webpage containing the HTML, CSS, and JavaScript.
  sir-randy.jpg** – Teacher's photo.
  README.md** – Project documentation.

🚀 How to Run the Project

1. Create a folder for the project.
2. Place the `index.html` file inside the folder.
3. Place the teacher's photo inside the same folder.
4. Make sure the image filename matches the filename used in the HTML.
5. Open `index.html` using a web browser.

Make sure the filename in the HTML matches the actual image filename.

✏️ Editing the Teacher's Information

* Teacher's Day message
* Signature

* Footer message

This allows the card to be personalized for another teacher if needed.

## 💌 Teacher's Day Letter

The website includes an interactive letter.

Clicking the **"Open My Letter"** button displays the Teacher's Day message in an animated popup.

The letter can be closed by:

* Clicking the **Close Letter** button
* Clicking outside the letter
* Pressing the **ESC** key

🌙 Dark and Light Mode
